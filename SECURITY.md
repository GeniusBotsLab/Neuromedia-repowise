# Security policy

Не публикуйте в issues, pull requests или репозитории секреты, токены, ключи, пароли, персональные данные, клиентские материалы, production-конфигурацию, логи или резервные копии. Для ответственного сообщения об уязвимости используйте BotsLab@proton.me и не прикладывайте эксплуатационные данные в публичное обращение.

This derivative is maintained independently. For upstream vulnerabilities, also consult the upstream project's security guidance.
